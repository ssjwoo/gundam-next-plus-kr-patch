# 038 개발 릴리스 — 잔여 한글화·원본 데이터 복원

027에서 보고된 백식 호위 임무의 전투 중 랜덤 프리징을 조사하면서, 문자열로 오인해 번역했던 비텍스트 데이터와 문자 제어문 오류를 확인했습니다. 038에는 확인한 결함의 복원과 추가 한글화를 통합했습니다. **실제 게임 실행은 `NOT_TESTED`, 프리징과 결함의 직접 연결은 `UNCONFIRMED_RUNTIME_LINK`입니다.** 전체 한글화 완료 판정은 없습니다.

이번 추가분은 다음과 같습니다.

- 원본 바이트와 동일하게 비텍스트 39곳 복원: 수치·벡터 20곳, 내장 PNG 압축 데이터 1곳, 달성 조건 포인터 18개.
- 원문에 없는 ASCII `~`를 제거한 구두점 수정 3곳. 기존 제어문은 유지했습니다.
- 달성 조건 설명 47문구를 원본의 독립 문자열 경계에 맞춰 정리하고 선택 안내 2곳의 길이와 숫자값을 바로잡았습니다.
- 기존 추출기가 앞부분을 빠뜨린 대사 176개를 원본 포인터가 가리키는 전체 문장으로 다시 작성했습니다. 기존 문자열은 CP932 앞부분과 한글 뒤쪽이 섞여 호스트 코덱 검사에서 모두 거부됐고, 현재 전체 읽기가 통과했습니다.
- 프리 배틀 작품·스테이지 목록과 선택 안내 3면·36문구를 교체했습니다. 기존 설정 그림과 썸네일은 유지했습니다.

실제 최종 ISO에서 39곳의 복원, 번역 슬롯 3,953곳, 원본 목록의 포인터 5,682개와 달성 조건 포인터 49개를 검사했습니다. 내장 원본 PNG 3개는 바이트 일치와 디코딩을 통과했습니다. 추가 vsel01의 네이티브 그림 5개도 편집 결과와 일치했습니다. 원본 타이틀 로고 193면은 보호 정책을 통과했습니다. 각 빌드 단계는 선언한 범위 밖 ISO 바이트와 구조를 보존했고 폰트와 실행 코드는 유지했습니다. 원판 기반 xdelta를 다시 적용한 출력의 크기·SHA-256·CRC32도 일치했습니다.

이 검사는 모든 게임 문자열의 실제 소비나 의미 검수를 대신하지 않습니다. 이전 스캐너가 잘라 낸 비정렬 문자열 조각과 모드별 공유 이미지 소비 경로는 조사 중입니다. 원래 그대로 둔 건담 타이틀 로고는 미번역 UI 집계에 포함하지 않습니다. AI는 게임·에뮬레이터·CMD를 실행하지 않았고 사용자가 인게임 검수를 담당합니다.
