# 공개 배포 방침

이 저장소는 법적으로 소유한 일본판 게임 이미지에 적용할 패치의 제작 도구·문서·한글 초안을 공개합니다. 사용자 승인으로 배포하는 xdelta 차분은 Git 커밋에 넣지 않고 GitHub 릴리스 자산으로만 제공합니다. 사용자가 지원 원본 ISO를 직접 준비해야 하며 전체 게임 이미지와 추출 자산은 배포하지 않습니다.

현재 정식 버전은 **v1.0.0**입니다. 사용자가 내부 빌드 042를 간단히 플레이한 뒤 정식 배포를 승인했습니다. 정식 버전과 개발 릴리스의 구분은 배포 단계이며, 전체 게임 완주·한글화 전수 검수 여부는 [진행 현황](../PROGRESS.md)에 따로 기록합니다. 남은 한글화와 문맥 보완은 후속 업데이트로 이어갑니다. [승인 근거](../reports/runtime_042_release_acceptance_2026-10-08.json).

## 포함 가능

- 프로젝트에서 작성한 분석·빌드·검증 소스 코드
- 한글 번역 초안과 검수 상태
- 원문·원시 바이트·포인터를 제거한 ID별 한글 초안
- 원본 파일을 재배포하지 않는 주소·해시·구조 메타데이터
- 재현 절차와 고수준 검증 집계

## 포함 금지

- 원본 ROM·ISO·CSO·CHD
- 패치된 실행 가능 ISO나 전체 EBOOT
- 게임에서 추출한 그래픽·폰트·오디오·동영상·메모리 덤프
- PPSSPP 및 기타 제3자 바이너리
- 일본어 원문과 원시 바이트가 담긴 번역 AI 인계 패키지
- 라이선스를 확인하지 않은 폰트·도구·참고 자료

`.gitignore`는 위 파일 형식과 로컬 생성 디렉터리를 차단합니다. 새 형식을 저장소에 추가하기 전에 재배포 권한과 원본 데이터 포함 여부를 먼저 확인합니다.
