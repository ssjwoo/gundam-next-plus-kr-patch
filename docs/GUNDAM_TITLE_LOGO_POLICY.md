# 건담 타이틀 로고 원본 유지 정책

사용자 지시에 따라 **인게임의 모든 건담 작품·게임 타이틀 로고를 원본으로 유지**합니다. 작품 선택 탭, 배너·발광 변형, 미션 카드, 메인 게임 로고, 해금 화면과 `pbg0ff.pzz`가 대상입니다. 일반 UI·기체·파일럿명·미션·도움말은 한글화합니다.

복원은 원판에서 확인한 픽셀·색상 인덱스를 사용하며 같은 그림의 한글 이름을 보호합니다. 로고를 AI로 재생성하거나 다른 글꼴로 다시 쓰지 않습니다. 원본 팔레트·PZZ 할당·검사값과 최신 코드·폰트 수정을 유지합니다.

023에서 기존 편집 168멤버·311영역을 복원했고 최신 038의 보호 로고 193면 검사를 통과했습니다. 이 수는 확인한 보호 대상이며 전체 모드 한글화 완료 판정이 아닙니다. [복원 이력](HISTORY.md#revision-023), [현재 범위](../reports/graphics_scope_2026-10-05.json).
