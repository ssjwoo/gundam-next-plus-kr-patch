## 웹 AI에 전달할 문장

> 첨부 TXT의 해당 배치 임무·번호표·JSON 스키마대로 이미지 PDF 또는 텍스트 JSON을 순서대로 검수해줘. 실제 원문과 현재 한글을 대조하고 확인된 수정안을 반환해줘. 응답 한도가 다가오면 완료한 결과·미검토 ID·다음 항목 ID를 저장해줘. 이어서 진행할 때 기존 결과를 보존하고 마지막에는 JSON 하나로 합쳐줘.

실제 배치 TXT가 최신 기준·범위·스키마의 원본이다. 해당 PDF·JSON에 없는 번호를 검토 완료로 채우지 않는다. 이미지는 25개씩, 텍스트는 50개씩 진행하되 대표 한 항목으로 같은 계열 전체를 완료 처리하지 않는다.

## 공통 판독·보존 규칙

- 앞으로 **글자 없는 그림은 개별 확인 후 자료에서 제외**한다. 작은 글자·옅은 영문·판독 불명 문구는 남기며, 파일명·대표 그림·OCR 미검출만으로 계열 전체를 제외하지 않는다. 이미 전달한 배치 001~004는 그대로 보존한다.
- **건담 작품·게임의 장식 타이틀 로고는 원본 유지**다. 일반 글꼴의 기체·파일럿·팀 이름과 안내 문구는 번역·검수 대상이다. 그림·배경·숫자·버튼·아이콘·글리프 표는 구분한다.
- 자연스러운 기존 한글은 유지한다. 오역·명칭 불일치·누락·잘림은 실제 원문·현재 문구·위치와 함께 수정안을 낸다. 일반 영어를 익숙하다는 이유로 일괄 제외하지 않는다.
- 장음·중점·약칭·이름 순서는 그림에서 확인한다. 보이지 않는 원문을 기억만으로 채우지 않는다. 판독 불가능하면 `null`과 `uncertain`을 쓴다.
- 명칭 통일 제안은 관련 ID와 실제 표기를 함께 기록한다. 칸이 좁을 때의 짧은 대안도 인물·기체의 정체성을 보존한다.
- 아틀라스의 흰 번짐·겹친 문구·그림자·발광은 효과 레이어일 수 있다. 실제 문구와 구분하고 구조·소비 증거 없이 손상으로 단정하지 않는다.
- 위치는 native 그림 왼쪽 위 (0,0)의 대략 `[x0,y0,x1,y1]`이다. 측정하지 못하면 `bbox_px: null`과 위치 설명을 쓴다. PDF 좌표·확대 배율을 원래 좌표로 쓰지 않는다.
- 파일명으로 실제 모드·사용 화면을 확정하지 않는다. 체크 무늬는 PDF 투명 영역 배경이며 게임 픽셀이 아니다.

## 감독 AI의 통합

반환 JSON의 batch_id·baseline·그림/텍스트 ID·원문·영역/슬롯을 실제 소스와 대조한다. 확인한 수정안만 작은 배치로 편집한다. 기존 한글·보호 로고·폰트·숫자·팔레트·메시·컨테이너를 유지하고 GIM/PZZ 고정 할당·검사값·재읽기를 검증한다. 텍스트는 원문 소유 경계·고정 용량·제어 구문·포인터·폰트와 현재 슬롯 바이트를 검증한다. 웹 AI 결과는 승인·주입·실행 증거가 아니다.

039는 정적 검사·원판용 xdelta 재적용 PASS이며 게임 실행 NOT_TESTED다. 027 백식 호위 임무 프리징은 별도 열린 문제다. 전체 완료·프리징 해결을 선언하지 않는다. 실제 실행 검수는 사용자가 맡으며 반복 요청하지 않는다. 새 한글화 작업의 5시간 한도 잔여 30%에서 다음 세션 인계를 준비한다.
