# 개발 릴리스 021 — 이미지 한글화·첫 로딩 오류 수정

`next_plus_graphics_revision_021.xdelta`는 PSP 일본판 **NPJH50107** 원본 ISO에 적용하는 누적 차분 패치입니다. 이전 v19 패치의 후속 개발 릴리스이며, 020에서 보고된 PSP 로고 직후 첫 로딩 정지를 수정했습니다.

2026-10-03 사용자가 **021의 부팅 완료와 현재까지의 정상 게임플레이**를 보고했습니다. 이번 재시험의 기기·에뮬레이터별 결과와 플레이 범위는 별도로 제공되지 않았습니다. 전체 모드·전체 플레이 검수나 한글화 완료를 뜻하지 않습니다.

## 다운로드 및 적용

- [021 개발 릴리스](https://github.com/ssjwoo/gundam-next-plus-kr-patch/releases/tag/dev-2026-10-03-graphics-021)
- [next_plus_graphics_revision_021.xdelta 다운로드](https://github.com/ssjwoo/gundam-next-plus-kr-patch/releases/download/dev-2026-10-03-graphics-021/next_plus_graphics_revision_021.xdelta)

합법적으로 보유한 **패치하지 않은 원본 일본판 ISO**를 사용하세요. v19·020 등 이전 패치 ISO에 덧씌우지 않습니다. 입력 파일명보다 아래 크기와 SHA-256이 중요합니다. 원본을 보존하고 별도 출력 파일을 만듭니다.

```text
xdelta3 -d -s original_jp.iso next_plus_graphics_revision_021.xdelta next_plus_graphics_revision_021.iso
```

`original_jp.iso`는 위 명령에서 사용하는 원본 파일명 예시입니다. 본인 원본 파일명에 맞게 바꾸거나 xdelta 패처에서 원본과 패치, 출력 위치를 선택하세요. 폰트는 패치 결과 ISO에 내장되며 별도 PSP 폰트 추출이 필요하지 않습니다.

## 반영한 작업

- 사용자가 다듬은 번역을 재검토하고 연결이 확인된 368개 텍스트 슬롯을 갱신했습니다. 3,930개 슬롯의 읽기 검사와 미션 274개의 완전한 3줄 레코드 반영을 확인했습니다.
- 메인 모드 선택 화면, 조작 설명서 10페이지, 스킬·기체·파일럿 이름, 공통 UI·브리핑 이름·작품 로고·카드 로고·해금 안내 등을 반영했습니다. 수정된 이미지 643면을 포함하는 PZZ 466멤버를 ISO에서 대조했습니다. 상세 범위는 [이미지 작업 기록](GRAPHICS_2026-10-03.md)을 보세요.
- 020이 잘못 보존했던 PZZ 끝의 16바이트 검사값을 다시 계산했습니다. 021의 압축 본문·이미지·텍스트·폰트는 020과 동일하며, 이 수정은 각 멤버의 검사값에만 적용했습니다. [첫 로딩 오류 수정 기록](BOOT_FAILURE_020_2026-10-03.md).

## 확인 범위와 남은 작업

- **정적 검증 PASS:** 466멤버의 검사값, 원본 검사 함수 6개 사례 대조, ISO에서 다시 읽은 643면·보호 영역·텍스트·폰트 검사.
- **차분 재적용 PASS:** 지원 원본에 xdelta를 적용한 출력의 크기와 SHA-256이 위 021 ISO와 일치합니다.
- **사용자 실행 확인:** 021 부팅 완료, 현재까지의 게임플레이 정상. 모든 장면의 이미지 배치·세이브·통신·장시간 플레이는 확인 완료로 처리하지 않습니다.
- **한글화는 계속 진행 중:** `pbg0ff.pzz`의 일본어 게임 로고가 남아 있고, NEXT PLUS 상태별 공유 리소스·동적 UV 연결과 전체 범위 조사는 미완료입니다. 게임 전체 텍스트 및 NEXT PLUS 이미지 전부 완료를 주장하지 않습니다.

문제를 보고할 때는 적용한 원본/출력의 SHA-256, 사용하는 기기 또는 에뮬레이터, 멈춘 시점이나 화면을 함께 알려주세요.

## 배포 내용

릴리스에는 위 xdelta 파일만 첨부합니다. 전체 게임 ISO·실행 파일·추출 자산은 업로드하지 않습니다. 원본 ISO는 사용자가 직접 준비합니다. 기존 [v19 개발 릴리스](https://github.com/ssjwoo/gundam-next-plus-kr-patch/releases/tag/dev-2026-09-26)는 이력으로 보관합니다.

폰트는 NanumGothic(NAVER)·Noto Sans JP(Google)의 OFL 1.1 자유 폰트 기반입니다. 차분 생성·적용에는 xdelta3를 사용했습니다. 프로젝트 도구와 공개 자료의 범위는 [공개 배포 방침](PUBLICATION_POLICY.md)에 정리했습니다.
