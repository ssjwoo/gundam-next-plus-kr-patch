# 개발 릴리스 023 — 원본 타이틀 로고·미션 프리징 수정

[023 개발 릴리스](https://github.com/ssjwoo/gundam-next-plus-kr-patch/releases/tag/dev-2026-10-03-graphics-023) · [next_plus_graphics_revision_023.xdelta 다운로드](https://github.com/ssjwoo/gundam-next-plus-kr-patch/releases/download/dev-2026-10-03-graphics-023/next_plus_graphics_revision_023.xdelta)

사용자가 요청한 수정의 반영과 NEXT PLUS 「타이거바움의 침입자」 전투 중 프리징 해결을 확인했습니다. 작품 선택 탭·작품 배너·미션 카드·메인 게임 로고·해금 화면의 건담 타이틀 로고는 원본으로 복원했습니다. 메뉴와 기체·파일럿명, 미션 등의 일반 텍스트는 한글화를 유지합니다.

021에서 발견한 문자 분류표 손상과 폰트 경로 충돌을 고친 022의 수정도 포함합니다. 023의 EBOOT·폰트·미션 데이터는 022와 동일합니다. [프리징 진단](https://github.com/ssjwoo/gundam-next-plus-kr-patch/blob/main/docs/MISSION_FREEZE_021_2026-10-03.md), [로고 복원 기록](https://github.com/ssjwoo/gundam-next-plus-kr-patch/blob/main/docs/ORIGINAL_TITLE_LOGOS_023_2026-10-03.md).

### 적용 방법

**패치하지 않은 NPJH50107 일본판 원본 ISO**에 적용하는 누적 차분입니다. 원본을 보존하고 별도 출력 파일을 만드세요. v19·021·022 등 이전 패치 ISO에 덧씌우지 않습니다. 아래 `original_jp.iso`는 원본 파일명 예시이며 실제 파일명에 맞게 바꾸세요.

```text
xdelta3 -d -s original_jp.iso next_plus_graphics_revision_023.xdelta next_plus_graphics_revision_023.iso
```

폰트는 패치 결과 ISO에 내장됩니다. 별도 PSP 폰트 추출이 필요하지 않습니다.

### 확인 범위

- 사용자 실행 확인: 요청한 수정 반영과 기존 미션 프리징 해결. 이번 확인의 기기별 결과와 반복 횟수는 별도로 제공되지 않았습니다.
- 정적 검사 PASS: 원본 ISO의 실제 466멤버·기존 643면 대조, 복원한 로고 168멤버·311영역과 유지한 한글 픽셀, 보호 로고 181면, PZZ 로더 검사값·파일 할당 구조.
- 원본 기반 차분 재적용 PASS: 출력의 크기·SHA-256이 위 023 ISO와 일치합니다. 현재 일반 UI 한글화 그래픽은 450멤버·617면입니다.
- 게임 전체 텍스트와 NEXT PLUS의 모든 상태별 리소스·동적 UV 조사는 진행 중이며 전체 모드·전체 플레이 완료 판정은 아닙니다.

릴리스에는 `.xdelta`만 첨부합니다. 전체 ISO·추출 이미지·폰트 파일은 배포하지 않습니다. 이전 021과 v19 릴리스는 이력으로 보관합니다. 폰트는 NanumGothic(NAVER)·Noto Sans JP(Google)의 OFL 1.1 기반이며 차분 생성·적용에는 xdelta3를 사용했습니다.
