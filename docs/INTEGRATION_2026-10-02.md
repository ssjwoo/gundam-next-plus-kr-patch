## 재현 조건과 도구

원본 프로필과 이전 숫자 수정 입력 해시는 [UPDATE_2026-10-02.md](UPDATE_2026-10-02.md)에 있다.
실제 원문·원시 바이트·주소를 포함하는 연결 계획, 워크북과 이미지 입력은 로컬에서만 보관한다.
새 도구는 기존 출력 덮어쓰기를 거부하며 정확한 입력 해시를 요구한다.

- `tools/extend_pgf_glyphs.py`: 지정한 자유 라이선스 폰트에서 글리프를 추가하고 기존 PGF 레코드 보존 확인.
- `tools/build_catalog_revision_iso.py`: 원문 연결 계획·슬롯·제어 토큰·폰트·코드·미션 포인터를 검증한 후 별도 텍스트 ISO 생성.
- `tools/render_localized_labels.py`: 검토한 글자 영역과 배경 샘플·복원 영역에 따라 한국어를 렌더링하고 보호 픽셀 검사.
- `tools/replace_gim_picture.py`, `tools/repack_pzz.py`: 팔레트 유지 교체와 고정 할당 재패킹.
- `tools/build_graphics_revision_iso.py`: 확인한 AFS 멤버만 교체하고 전체 ISO 변화 범위와 파일 구조 검사.

각 도구의 인자는 `--help`로 확인한다. 이미지 렌더링의 선택 의존성은 `requirements-graphics.txt`에 고정했다.
배경 복원은 [OpenCV 공식 inpaint API](https://docs.opencv.org/4.5.1/d7/d8b/group__photo__inpaint.html)를 사용하며 편집 마스크 안으로 제한한다.
공개 이미지 번역 자료는 `translations/graphics/`의 한국어 JSON 3개이며 원본 그림·일본어 원문을 포함하지 않는다.
