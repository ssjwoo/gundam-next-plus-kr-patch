# Gundam vs. Gundam NEXT PLUS 한글화 — 2026-09-26 개발 릴리스

## 이 릴리스에 들어간 것

`next_plus_development_v11_2026-09-26.xdelta` — 원본 일본판 ISO에 적용하는 차분 패치입니다.
**게임 코드 변경만 들어 있고 게임 데이터·폰트·그래픽은 들어 있지 않습니다.**

적용:

```
xdelta3 -d -s original_jp.iso next_plus_development_v11_2026-09-26.xdelta out.iso
```

| 패치 크기 | 1,652,987 바이트 |
| 패치 SHA-256 | `3939c1032e7446093ea884d3…` |
| 대상 타이틀 | NPJH50107 (일본판) |
| 원본 ISO SHA-256 | `a00c38959d52377b65f9afb5223e02c4ac5a876b8a33c998a7fe3f07dbf1feb3` |

## 이번에 해결한 것

1. **넥스트 플러스 미션 274건 번역·삽입** (271건 적용, 3건 용어 결정 대기)
2. **지도·설명 99건 번역** (자동 적용 98건, 구조 확인 대기 1건)
3. **영문·숫자가 화면에 안 나오던 문제 해결** — 원인은 펌웨어 한국어 폰트(`kr0.pgf`)의
   라틴 글리프·메트릭이었습니다. 게임이 펌웨어 폰트를 여는 호출을 `sceFontOpenUserFile`로
   바꿔 **폰트를 우리가 통제**하게 했습니다.
4. **숫자 표기 복원** — 폰트 문제 때문에 임시로 `숫자 → 한글 수사`로 적던 것을 되돌려
   `60초`, `3기`처럼 원래대로 적습니다.
5. 디코더 한글 기준값을 `0xAC00` → `0x0100`으로 옮겨 폰트 문자맵을 약 11,400칸으로 압축.

## 폰트 준비 (최초 1회)

이 패치는 폰트를 **메모리 스틱에서 읽습니다**:
`ms0:/PSP/SAVEDATA/NPJH50107/kr.pgf`

소니 폰트를 재배포하지 않기 위해, 사용자가 자기 PSP 펌웨어에서 폰트를 뽑아 씁니다.
`tools/make_subset_pgf.py`가 그 도구입니다.

```
# 1) PSP flash0에서 kr0.pgf를 꺼내 둡니다 (커펌 사용)
# 2) 필요한 글리프 844자만 뽑아 작은 PGF를 만듭니다
python tools/make_subset_pgf.py \
    --source kr0.pgf \
    --chars tools/glyph_set_ko.txt \
    --output kr.pgf
# 3) 메모리 스틱에 넣습니다
#    ms0:/PSP/SAVEDATA/NPJH50107/kr.pgf
```

게임의 libfont가 열 수 있는 폰트 크기는 대략 **160KB**까지입니다(64KB·128KB·160KB 성공,
192KB 실패). 위 도구의 출력은 **108,845바이트**라 여유가 있습니다.

## 확인한 동작 (PPSSPP v1.20.4 개발 빌드)

- 미션 1 제목과 설명 두 줄이 한국어로 표시
- 메인 메뉴 안내문에서 `2인 협력 플레이도 가능!`의 **`2`**와 **마침표**가 표시
  (폰트 문제 해결 전에는 둘 다 사라졌습니다)
- 폰트 로드: `sceFontOpenUserFile` → handle `09C47060`, error `0`

## 아직 안 한 것

- **실기 PSP 검증** — 같은 libfont·같은 경로(`ms0:`)를 쓰므로 동작할 것으로 보지만 확인 전입니다.
- **미번역 구간** — 이 폰트에는 가나·한자가 없어 일본어 원문이 한글 글리프로 잘못 나옵니다.
  자유 폰트(OFL)에서 가나·한자까지 넣는 생성기(`tools/make_pgf_from_ttf.py`)를 준비해 뒀지만,
  실기 libfont의 형식 검증(`break`)을 아직 통과하지 못했습니다.
- 이미지 글자(4,272개 그래픽 표면) 작업
- 번역 독립 검수

## 저장소에 함께 넣은 도구

| 파일 | 하는 일 |
| --- | --- |
| `tools/make_subset_pgf.py` | 기존 PGF에서 필요한 글리프만 뽑아 작은 PGF를 만듭니다 |
| `tools/make_pgf_from_ttf.py` | 자유 폰트(TTF/OTF)에서 PGF를 굽습니다 (진행중) |
| `tools/glyph_set_ko.txt` | 패치가 필요로 하는 글리프 목록 (844자) |

두 도구 모두 이 프로젝트에서 작성한 코드입니다.

## 라이선스·배포

- 이 패치와 도구는 게임 원본 데이터를 담지 않습니다. 원본 ISO는 사용자가 직접 준비합니다.
- `make_pgf_from_ttf.py`는 MIT 라이선스 도구(`r3trob0y/TTF-OTF-2-PGF`)의 래스터라이즈 방식을
  참고했습니다. 자세한 내용은 `docs/RESEARCH_NOTES.md`를 보세요.
