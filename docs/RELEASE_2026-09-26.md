## 이번에 해결한 것

1. **글리프 없는 문자 자리에 `!`가 찍히던 문제.** 문자맵에서 매핑하지 않은 칸을 0으로
   남겨둔 것이 원인이었습니다. 진짜 폰트(`kr0.pgf`)처럼 센티넬 `0x3FFF`로 채우고 글리프
   0번을 공백으로 바꿨습니다. 수정 전후 파일은 딱 7바이트만 다릅니다.
2. **`%t` 토큰이 엉뚱한 한글로 나오던 문제.** `%t`가 실행 중에 치환되는 자리가 인덱스
   8226이고 `찢`(U+CC22)의 자연 인덱스도 8226이라 충돌했습니다. 8226을 런타임 전용으로
   예약하고 `찢`을 인덱스 12000으로 옮겼습니다.
3. **미션 승리/패배 조건 숫자가 터무니없이 크게 나오던 문제.** 게임은 파일 오프셋
   `0x28D3B4`의 십진수 테이블(`０１２３４５６７８９`)을 **한 글자당 2바이트로** 읽습니다.
   이전 빌드가 이 테이블을 ASCII 1바이트로 바꿔 놓아서, 숫자 하나마다 글자가 둘씩 나왔습니다
   (값 10 → `2301`, 3 → `67`). 테이블 바이트를 원본으로 되돌리고, 그 바이트가 디코더를
   거쳐 가리키는 코드에 숫자 글리프를 넣었습니다.
4. **용어 통일** — `악마 건담` → `데빌 건담` (`デビルガンダム` 표기와 일치).
5. **자유 폰트로 전환.** 소니 `kr0.pgf`에서 뽑은 서브셋 대신 NanumGothic(OFL)과
   Noto Sans JP(OFL)로 구운 PGF를 씁니다. 재배포 제약이 사라졌습니다.
6. **글리프 RLE 구현.** 전에는 리터럴만 써서 폰트가 두 배 가까이 컸습니다. 검증된
   니블 RLE(`ttf2pgf`와 405/405 케이스 바이트 동일)를 넣어 한글 폰트가
   139,696 → 100,988바이트가 됐습니다.
7. **번역 확대.** 외부 모델 검토분 2,125행 + 슬롯 초과 해결 179행을 반영해
   1,624행 → **4,271행**이 됐습니다. 미션 제목·설명은 같은 문자열을 쓰는 미션 패키지의
   승인된 번역을 재사용했습니다.
8. **폰트 크기 한계 재측정.** 이전 메모의 "160KB"는 방향은 맞지만 부정확합니다.
   **139KB 성공 / 165KB 성공 / 235KB 실패**(열리지만 아무것도 안 그려짐).

## 확인한 동작 (PPSSPP v1.20.4 개발 빌드)

- 게임이 ISO 안의 진짜 `LIBFONT.PRX`(소니 libfont)를 로드하는데, 우리 폰트를
  **`break` 0회**로 받아들입니다.
- 메인 메뉴 설명 패널에 번역된 한국어 문단이 표시됩니다.
- 자동저장 안내문이 `메모리 스틱 듀오™`로 표시됩니다.
- 미션 화면에 새로 번역한 `스킬이 선택되지 않았습니다`가 표시됩니다.

## 아직 안 한 것

- **실기 PSP 검증** — 같은 libfont·같은 경로를 쓰지만 확인 전입니다.
  조건 숫자가 `３기`, `１０기`처럼 작게 나오는지도 실기에서 볼 항목입니다.
- **PZZ 데이터 파일의 텍스트** — `MS 편집` 화면 스킬 설명이 아직 읽히지 않는 한글로
  나옵니다. 이 문자열은 EBOOT이 아니라 압축 데이터 파일 쪽이고, 원문의 인덱스 쌍이
  한글 인덱스와 겹쳐서 생기는 문제입니다.
- **이미지 글자** (4,272개 그래픽 표면)
- **번역 독립 검수** — 4,271행은 아직 `unapproved_draft`입니다.

## 라이선스·배포

- 이 패치와 도구는 게임 원본 데이터를 담지 않습니다. 원본 ISO는 사용자가 직접 준비합니다.
- 폰트는 OFL 1.1(NanumGothic — NAVER, Noto Sans JP — Google)이라 함께 배포할 수 있습니다.
- 공개 저장소에는 코드·문서·한글 초안만 들어갑니다. ISO와 xdelta는 게임 데이터를 담고 있어
  릴리스 자산으로만 배포합니다.
