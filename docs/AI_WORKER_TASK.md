## 다음 웹 AI 검수에 전달할 문장

> 첨부 TXT의 배치 임무·번호표·스키마대로 실제 PDF 또는 JSON을 검수해줘. 원문과 현재 한국어를 대조하고 확인된 수정만 별도 필드에 제안해줘. 응답 한도에 다가오면 완료 결과·미검토 ID·다음 ID를 저장하고 이어서 합쳐줘. 없는 번호를 검토 완료로 채우거나 사용자 방침을 새로 만들지 마.

이미지는 25개, 텍스트는 50개 단위로 검토합니다. 대표 한 항목을 계열 전체 승인으로 확대하지 않습니다. 자연스러운 기존 한국어를 보존하고 오역·누락·잘림·명칭 불일치를 원문 위치와 함께 제안합니다. 판독 불가능하면 `null`과 `uncertain`, 대략적인 native 좌표 `[x0,y0,x1,y1]`와 위치 설명을 반환합니다.

건담 작품·게임 타이틀 로고는 원본 유지입니다. 일반 기체·파일럿·팀 이름과 기능 UI는 한글화 대상입니다. 글자 없는 그림은 개별 확인 후 제외하고 숫자·아이콘·버튼·글리프 표·장식·발광을 문장과 구분합니다. **일반 영문 전체를 유지한다는 방침은 없습니다.** 곡명·기술 방식·식별 코드는 각 기능과 근거로 판단합니다. 원문·현재 값·제어 토큰·숫자·고정 용량을 보존하고 화자나 보이지 않는 글자를 추측하지 않습니다.

## 감독 AI의 통합 기준

반환 batch_id·기준 해시·ID·원문·영역을 실제 소스와 대조합니다. 각 제안을 독립 검토하고 원문 소유 경계·포인터·용량·폰트·제어 구문을 확인합니다. 이미지는 실제 native 글자 칸을 측정하고 보호 픽셀·다른 그림·모델·팔레트·컨테이너·고정 할당·PZZ 검사값을 유지하며 재추출해 직접 확인합니다. 원판용 xdelta를 새로 만들어 전체 재적용 해시·크기를 비교합니다. 외부 결과는 승인·주입·실행 증거가 아닙니다.

042의 정적 검사·원판 재적용은 PASS, 게임 실행은 NOT_TESTED입니다. 027의 백식 호위 프리징은 열린 문제이며 023의 타이거바움 해결과 구분합니다. 실제 실행 검수는 사용자가 담당합니다. 새 한글화 작업은 5시간 한도의 **잔여 30%**에서 새 배치를 멈추고 다음 세션 인계를 준비합니다.
