# 건담 타이틀 로고는 원본 유지

2026-10-03 사용자가 작품 선택 탭 사진을 제시하며 **인게임의 모든 건담 작품·타이틀 로고를 원본으로 복원하고 앞으로 번역하지 말 것**을 지정했다. 이 지시는 기존 로고 한글화 계획을 대체한다.

적용 대상은 작품 선택 탭, 작품 배너와 발광 변형, 미션 카드에 합성된 작품 로고, 게임 자체의 타이틀 로고, 해금 화면의 작품 로고·배경이다. 아직 수정하지 않은 `pbg0ff.pzz` 게임 로고와 영문 작품 로고도 원본으로 유지한다. 기체·파일럿 이름, 메뉴, 미션, 도움말 등 일반 텍스트 한글화는 계속 유지한다.

복원은 원본 ISO에서 확인한 리소스의 픽셀·색상 인덱스를 정확히 사용한다. 같은 이미지에 한글 이름이 있으면 해당 이름 영역을 보호한다. AI 재생성이나 새 글꼴로 로고를 재작성하지 않는다. PZZ 크기·할당 구조·로더 검사값을 검증하고, 022의 폰트 경로 수정은 유지한다. 프리징 조사용 022는 별도로 보존하며 후속 로고 후보의 정적 통과를 프리징 해결이나 실행 통과로 간주하지 않는다.

작업 중 검증이 끝난 임시 파일과 중복 중간 산출물은 정리한다. 원본 ISO, 사용자 제공 자료, 현재 시험 후보, 재현에 필요한 원본·마스크·manifest·검증 기록은 보존한다. 대용량 차분 재적용은 출력 스트림을 해시 검사하여 중복 ISO를 만들지 않는다.

현재 복원 배치: 기존 로고 편집 168멤버·311영역. 작품 배너 16, 선택 탭 은행 3, 미션 카드 142, 메인 게임 로고 1, 해금 화면 6멤버다. 이는 확인된 **기존 로고 편집을 되돌리는 배치**이며 NEXT PLUS 전체 번역 완료 판정은 아니다.
