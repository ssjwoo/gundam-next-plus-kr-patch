## 027 — 추가 이미지·텍스트 한글화 개발판

023을 기준으로 이미지 272면(255개 PZZ), 그래픽 글자 1,174항목과 ELF data 텍스트 13곳을 추가했습니다. 조작 안내, 갤러리·전투 파일럿 이름, 갤러리 메뉴·곡 이름, 일반 크레딧, 해금 안내, 동방불패 문구, 전투 시작 대상 카드, 결과·설정 화면과 프리 배틀 기체 이름 66개를 포함합니다. 건담 작품·게임 타이틀 로고는 원본을 유지합니다.

023에서 사용자가 확인한 미션 프리징 수정과 폰트 경로·문자 분류표 수정을 포함합니다. **027 추가분의 인게임 검수는 아직 진행 전(NOT_TESTED)이며, 023의 사용자 실행 확인을 027의 검수 결과로 간주하지 않습니다.** [추가 작업 기록](https://github.com/ssjwoo/gundam-next-plus-kr-patch/blob/main/docs/GRAPHICS_2026-10-04.md).

### 적용 방법

**패치하지 않은 NPJH50107 일본판 원본 ISO**에 적용하는 누적 차분입니다. 원본을 보존하고 별도 출력 파일을 만드세요. v19·021·023 등 기존 패치 ISO에 덧씌우지 않습니다. 아래 `original_jp.iso`는 원본 파일명 예시이며 실제 파일명에 맞게 바꾸세요.

```text
xdelta3 -d -s original_jp.iso next_plus_graphics_revision_027.xdelta next_plus_graphics_revision_027.iso
```

폰트는 패치 결과 ISO에 내장됩니다. 별도 PSP 폰트 추출은 필요하지 않습니다. 적용에 문제가 있으면 원본과 출력의 크기·해시를 아래 표와 비교하세요. 문제 보고 시 사용한 패치 버전, 기기, 발생 화면과 행동을 함께 남겨주세요.

### 확인 범위와 남은 작업

- 정적 검사 PASS: 최종 ISO에서 변경된 255개 PZZ·272면 재추출 대조, 고정 할당·AFS 구조·PZZ 검사값, 보호 픽셀과 원본 타이틀 로고 193면을 확인했습니다.
- 실행 코드와 폰트는 023의 바이트를 유지했고 ELF는 선언한 data 텍스트 13곳만 변경했습니다. 인코딩 회귀 검사 7개와 공개 카탈로그 기반 쓰기 계획 재현도 통과했습니다.
- 원본 기반 xdelta 재적용 PASS: 복원 출력의 전체 크기와 SHA-256이 위 027 ISO와 일치합니다.
- 027 실기·에뮬레이터 실행 결과는 NOT_TESTED입니다. 전체 게임·NEXT PLUS 한글화와 전체 플레이 완료 판정은 아닙니다.
- 프리 배틀 작품·스테이지 목록과 작은 선택 안내, 모드별 이미지 소비 경로·전수 범위, 예전 번역 카탈로그와 현재 원문 슬롯 연결은 남아 있습니다.

릴리스에는 `.xdelta`만 첨부합니다. 이전 릴리스는 보존합니다. 폰트는 NanumGothic(NAVER)·Noto Sans JP(Google)의 OFL 1.1 기반이며 차분 생성·적용에는 xdelta3를 사용했습니다. 게임 ISO·추출 이미지·폰트 파일은 별도로 배포하지 않습니다.

공개 다운로드 15,161,344바이트와 SHA-256을 로컬 패치와 대조해 PASS를 확인했습니다. 릴리스 소스 커밋은 `7afae02fa3a9c1b14e0e066ea3132f47e8b74482`이며 게시 근거는 `reports/release_027_2026-10-04.json`입니다.
