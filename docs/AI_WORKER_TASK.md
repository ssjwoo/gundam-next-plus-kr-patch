# 웹 AI 임무 프롬프트 - 잔여 이미지 검수·번역

첨부 두 개로 진행한다. 감독 AI가 **임무·배경·그림 번호표를 합친 TXT 하나**와 **원판/해당 작업본 비교 PDF 하나**를 준비한다. 웹 AI에는 로컬 파일 접근·ZIP 해제·ISO 분석·이미지 편집을 요구하지 않는다. 실제 편집·주입·빌드·릴리스는 감독 AI가 맡는다. 실제 첨부물은 로컬 `work/ai_worker_handoff_2026-10-06/web/`에 보관한다.

## 현재 배치와 반환 방식

| 배치 | 기준 | 그림 | 상태 |
|---|---|---|---|
| 001 | 038 | 50 | 반환 결과 수신·감독 검수; 지명 2곳을 039에 반영 |
| 002 | 039 | 422 | 대규모 검수 자료 준비; 결과 미수신 |

배치 002는 로컬 `work/ai_worker_handoff_2026-10-06/web_batch_002/`의 `WEB_AI_HANDOFF_BATCH_002.txt`와 `IMAGE_REVIEW_BATCH_002.pdf` 두 개다. 일반 영문·판독 보류 재검토 20개, 공용 UI·메뉴 115개, 기체별 스킬 66개, 기체별 정보 134개, 조작·기체별 안내 76개, 해금 안내 11개를 묶었다. 확정 미번역 개수나 전체 게임 범위라는 뜻은 아니다.

웹 AI는 **첨부 TXT에 적힌 해당 배치의 기준·번호표·스키마를 우선**한다. 배치 002의 결과는 `web_ai_result_batch_002.json`, 식별자는 `web_graphics_002_039`다. 이미지 ID는 첫 배치에서 재검토할 20개와 신규 G051–G452를 사용한다. PDF 순서대로 검토하고 응답 한도가 다가오면 실제 완료한 항목과 미검토 ID·다음 ID를 저장한 유효한 JSON을 반환한다. 이어서 검토할 때 기존 결과를 보존한다.

건담 작품 타이틀 로고는 원본 유지다. 일반 영문 UI는 익숙한 영어라는 이유만으로 일괄 제외하지 않는다. 자연스러운 기존 한국어는 보존하고 뜻·명칭·누락·잘림을 개별 검수한다. 원판/039의 실제 PZZ 검사값·AFS 이름·번호·크기·픽셀을 바인딩한 자료이며, 사용 모드·동적 UV·실행 성공을 증명하지 않는다.

## 첫 배치 001의 임무 예시

당신은 PSP 『기동전사 건담 VS. 건담 NEXT PLUS』 한글화의 **이미지 판독·번역·검수 담당**이다. 첨부 TXT와 PDF만 읽고 아래 형식의 결과를 제출하라. 감독 AI가 결과를 검토하고 게임 파일에 반영한다.

### 기준과 범위

- 기준은 038이다. 메인 모드 선택 화면·NEXT PLUS의 일반 UI가 우선이다. 이번 50개 그림은 첫 조사 배치이며 전체 게임이나 확정 미번역 목록이 아니다.
- PDF 왼쪽은 원판, 오른쪽은 실제 038의 동일 그림이다. 텍스처·여러 UI 조각을 모은 아틀라스이며 실제 인게임 화면은 아니다. 번호·part·picture·원래 픽셀 크기는 TXT 번호표를 따른다.
- 파일명으로 모드를 확정하지 않는다. 사용 화면·동적 UV 관계는 감독 AI가 조사한다. 웹 AI의 모드 판단은 추정으로 표시한다.
- **모든 건담 작품·게임의 장식 타이틀 로고는 원본 유지**다. 일반 글꼴의 작품명·기체·파일럿명·설명·조작 안내는 번역 대상이다. 혼합 그림은 영역별로 구분한다.
- 숫자, 알파벳 글리프 표, 버튼 아이콘, 장식, 배경과 이미 자연스러운 한국어는 유지한다. 영어 일반 UI는 번역 필요 여부와 이유를 적는다.
- 과거 카탈로그보다 PDF 오른쪽 실제 038 픽셀을 우선한다. 읽지 못한 글자나 애매한 의미를 추측으로 채우지 않는다.

### 할 일

1. PDF의 모든 그림 번호를 개별 검토한다. 대표 그림으로 계열 전체를 판정하지 않는다. 체크 무늬는 투명 영역을 보여주는 PDF 표시이며 게임 픽셀이 아니다.
2. 현재 038의 미번역 일반 UI는 보이는 원문, 자연스러운 한국어, 폭이 좁을 때의 짧은 대안, 의미·줄바꿈·명칭 근거를 제안한다. 이미 번역됐으면 중복 교체하지 않는다. 오류·잘림은 별도 지적한다.
3. 위치는 원래 그림에서 왼쪽 위 (0,0) 기준의 대략적인 `[x0,y0,x1,y1]`로 기록한다. 측정할 수 없으면 `bbox_px: null`과 위치 설명을 쓴다. PDF 페이지 좌표를 픽셀 좌표로 쓰지 않는다.
4. 아틀라스의 텍스트 셀을 개별 검토한다. 문장 조각·글리프 표·상태 변형을 구분하고, 조각 연결 순서를 근거 없이 지어내지 않는다.
5. 가능하면 `web_ai_result_batch_001.json` 파일로, 파일 생성이 불가능하면 JSON 코드 블록으로 반환한다. 미완료 그림 번호를 명시한다.

### 결과 형식

```json
{
  "schema_version": 1,
  "batch_id": "web_graphics_001_038",
  "baseline_revision": "038",
  "reviewed_image_ids": [],
  "unreviewed_image_ids": [],
  "images": [
    {
      "image_id": "G001",
      "status": "uncertain",
      "visible_content": "실제 확인한 내용",
      "mode_guess": null,
      "regions": [
        {
          "region_id": "G001-R01",
          "classification": "uncertain",
          "language": "unknown",
          "source_text": null,
          "current_text": null,
          "target_ko": null,
          "short_ko": null,
          "bbox_px": null,
          "location": "그림 내부 위치 설명",
          "confidence": "low",
          "reason": "판독·번역·유지 근거"
        }
      ],
      "issues": []
    }
  ],
  "summary_ko": "확인한 누락·미확정 사항만 요약"

```

`status`와 `classification`은 `needs_translation`, `already_localized`, `no_text`, `preserve_logo`, `preserve_symbols`, `mixed`, `uncertain` 중 하나다. 혼합 그림은 `mixed`와 영역별 항목을 쓴다. `confidence`는 `high`, `medium`, `low`다. 판독 불가능한 원문은 `null`이며 실제 보지 않은 그림을 검토 완료로 넣지 않는다.

### 하지 않을 일

전체 한글화 완료, 실제 게임 검수, 프리징 해결, 패치 제작을 선언하지 않는다. 027의 백식 호위 임무 랜덤 프리징은 별도 열린 문제다. 038 실행은 NOT_TESTED이며 사용자에게 반복 실행 검수를 요구하지 않는다. 응답 한도가 부족하면 완료한 결과와 다음 그림 번호를 반환한다.

## 감독 AI의 통합

반환 JSON을 실제 그림 번호·원판/038 멤버 해시와 대조한다. 원문·번역·영역·모드 관계를 확인한 항목만 작은 배치로 편집한다. 기존 한글·원본 로고·폰트·숫자·포인터를 유지하고 GIM/PZZ 고정 할당·검사값·재읽기를 검증한 뒤 새 후보를 빌드한다. 실제 실행 검수는 사용자가 맡는다. 새 한글화 세션은 5시간 한도 잔여 30%에서 인계한다.
